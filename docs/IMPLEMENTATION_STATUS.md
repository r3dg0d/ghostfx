## Unsupported or approximated effects

- **No previous-frame feedback** in Ghostty: phosphor persistence (`amber-terminal`, `retro-radar`), trails and accumulation (`snow-accumulation`) are analytic approximations.
- **No mouse input** (`iMouse` is always 0): interactive shaders react to the **cursor** instead (`typing-ripples`, `keyboard-glow`).
- **No access to the desktop behind the window**: glass shaders use procedural backdrops.
- **Cell size is not exposed**: scanlines cannot lock to text rows.
- `crt-power`: Ghostty only redraws unfocused terminals when their content changes, unless custom-shader-animation = always.
- `retro-radar`: Persistence is computed from the sweep angle, since Ghostty provides no previous frame.
- `keyboard-glow`: Reacts to cursor movement (Ghostty 1.2+), which is the closest proxy for key presses a shader can see.
- `typing-ripples`: Uses the cursor uniforms (Ghostty 1.2+); ripples start whenever the cursor moves or changes colour.
- `fractal-zoom`: 32-bit floats limit the zoom depth; the dive loops every cycle with a cross-fade.
- `frosted-glass`: Ghostty cannot see the desktop behind the window, so the "backdrop" is procedural.
- `snow-accumulation`: Without frame feedback the snow cannot pile up over time; caps are drawn wherever a glyph has empty space above it.
- `cmb-noise`: An artistic pattern made from fractal noise, not real CMB data.
